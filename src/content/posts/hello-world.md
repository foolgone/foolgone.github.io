这是这个博客的第一篇文章。与其写「Hello World」，不如把建站过程中的几个决定记下来，以后回头看会更有意思。

## 为什么要重写

上一版博客是五年前搭的。它还能用，但每次想改点东西，我都要先花十分钟回忆当初为什么这么写。工具会老化，判断也会变，重写是让两者重新对齐的机会。

我给自己定了三个约束：

1. **不引入需要长期维护的服务端**。文章是文件，构建是命令，部署是推送。
2. **首屏必须快**。目标是在 3G 网络下两秒内看到可读内容。
3. **写作体验优先**。打开编辑器就能写，不用管路由、组件和样式。

## 为什么是 Astro

静态站点生成器很多，选 Astro 的原因是它的默认值和我想要的接近：默认输出 HTML，默认不加载 JavaScript，需要交互的地方才单独加水。

```ts
// 内容集合：文章就是目录里的 Markdown 文件
const posts = defineCollection({
  loader: glob({ base: './src/content/posts', pattern: '**/*.md' }),
  schema: z.object({
    title: z.string(),
    pubDate: z.coerce.date(),
    tags: z.array(z.string()).default([]),
  }),
});
```

这段配置的意义在于：文章的元信息有了类型约束，写错字段构建时就会报错，而不是等页面渲染出来才发现。

## 几个具体的取舍

### 搜索用自建索引，不用第三方

站内搜索只需要一个 JSON 索引加几十行前端代码。中文按子串匹配反而比分词更准，也不用额外跑构建步骤。

> 工具的选择标准不是「功能最多」，而是「需要我操心的部分最少」。

### 暗色模式用 CSS 变量

没有用任何主题库。根节点上的一个 `data-theme` 属性切换两组变量，配合一段内联脚本在首屏渲染前读 `localStorage`，避免闪白。

### 字体只用系统字体

中文 Web Font 动辄几 MB。正文交给系统字体，标题用衬线族回退链，视觉上足够，代价是零。

## 现在的结果

- 构建产物约 300KB，含全部页面
- 无阻塞渲染的第三方脚本
- 新增一篇文章只需要新建一个 `.md` 文件
